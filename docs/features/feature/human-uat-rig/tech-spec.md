# Tech Spec: Human UAT Rig

## Data

`scripts/uat/human/cases.json`

```
{
  "version": 1,
  "cases": [
    { "id", "kind": "mcp_mode" | "surface", "tool"?, "mode"?, "setup", "question" }
  ]
}
```

`tool` and `mode` are set for `kind: "mcp_mode"` and are the join key against the
shipped schema. `id` is `tool/mode` for modes and `area/action` for surfaces.

## Contract

`scripts/contracts/humanuat` runs as part of `go test ./...`. It reads
`cmd/browser-agent/testdata/mcp-tools-list.golden.json` — the byte-for-byte document
`tools/list` returns, and the same source `cat-33` enumerates at run time — and holds
the inventory to six invariants:

| Invariant | What it prevents |
|---|---|
| Every schema mode has exactly one case | A mode shipping with nobody asking what it does; a duplicate inflating the denominator |
| No case names a mode that no longer ships | A tester spending a run on a mode that was removed |
| Every required non-MCP surface has a case | The parts with no schema entry going untested precisely because nothing enumerates them |
| No question contains unfalsifiable wording | "Does it work?" being answered yes by a mode that returned nothing |
| No two cases share a question | Two modes not being told apart, so at most one is judged |
| Every case has a setup ≥15 chars and a question ≥25 chars ending in "?" | A case that cannot be run as written |

A seventh test is the control for the other six: they all read one file, and a file that
failed to load would make each pass vacuously, so `loadInventory` fails rather than
returning empty and the control asserts the inventory covers at least as many cases as
there are shipped modes.

## Why the golden and not a live daemon

The contract must run in the ordinary Go suite, on a machine with no Chrome and no
daemon. The golden is regenerated by `UPDATE_GOLDEN=1 go test ./internal/schema` and is
already the thing that fails when the schema changes, so binding to it means a new mode
cannot land without either a case or a deliberate, visible edit to this contract.
